# Deploy runbook

One-time setup for the site, then the loop for every new game.

## 1. Create the repo (once)

The `gh` CLI is not installed and an SSH key cannot create repos, so this step is
manual: on github.com create a **public** repo named `viethoa`, empty (no README,
no .gitignore, no licence).

Then, from `~/dev/viethoa`:

```bash
git remote add origin git@github.com:hhhai0304/viethoa.git   # already set
git push -u origin main
```

Pages only works for public repos (private needs GitHub Pro).

## 2. Turn on Pages (once)

Repo → Settings → Pages → **Source: Deploy from a branch**, branch `main`, folder
`/ (root)`. The `.nojekyll` file is committed, so filenames with leading
underscores survive.

Verify: `https://hhhai0304.github.io/viethoa/` and `/temtem/`.

## 3. Search Console (once)

1. Add the property `https://hhhai0304.github.io/viethoa/` (prefix property, not
   a domain property).
2. Verify with the HTML-tag method: paste the meta tag into `templates` in
   `build.py` (`shell()`), or use the file method by dropping the verification
   file in the repo root.
3. Submit `sitemap.xml`.

Ranking for an exact-match phrase like "Temtem Việt Hóa" on a zero-competition
term is mostly about being *indexed* and having a few inbound links. Off-page
(one YouTube video, one Reddit post, one Facebook group, one voz thread) does
more than on-page tweaking at this stage.

## 4. Custom domain (optional, later)

`viethoa.haiho.net` → GitHub Pages, without putting load on the Pi:

1. Cloudflare DNS: `CNAME viethoa → hhhai0304.github.io`, **DNS only** (grey
   cloud, not proxied) — traffic goes straight to GitHub.
2. Set `custom_domain` in `content/site.json` to `viethoa.haiho.net`, set
   `base_url` to `https://viethoa.haiho.net`, run `python3 build.py`
   (this writes `CNAME`), commit, push.
3. GitHub → Settings → Pages → Custom domain → enter it, enable *Enforce HTTPS*.

`base_url` must be updated at the same time, otherwise canonical/og URLs keep
pointing at the github.io host.

## 5. Publish a release

The website links to `releases/latest`, and the installer files come from the
`viet-hoa` pipeline:

```bash
# on hai-pc, after the packer produced dist/
gh release create temtem-v1.0.0 dist/Temtem_Windows.zip dist/Temtem_Linux.tar.gz \
  --title "Temtem Việt Hóa v1.0.0" --notes "See /temtem/#thay-doi"
```

Asset names must match the page: `Temtem_Windows.zip`, `Temtem_Linux.tar.gz`.
Upload with `gh` from the PC or drag-and-drop in the web UI — do not commit the
binaries into the repo.

## 6. Donate block

Off by default. To enable, fill `content/site.json`:

```json
"donate": { "enabled": true, "bank": "Techcombank",
            "account": "1903xxxxxxxx", "holder": "NGUYEN VAN A",
            "bank_id": "970407" }
```

`bank_id` is the VietQR BIN (Techcombank `970407`, Vietcombank `970436`,
MB `970422`, ACB `970416`, TPBank `970423`). The QR image is generated by
`img.vietqr.io` at render time with the per-game transfer note.

## 7. Adding a game

```bash
cp content/games/temtem.json content/games/<slug>.json   # edit it
python3 build.py                                          # writes <slug>/index.html
git add -A && git commit -m "add <Game> việt hóa page"
```

`slug` becomes the URL. Keep `summary` under 160 characters (it is the meta
description), and keep the H1 as `<Game> Việt Hóa` — that is the phrase people
search.

Screenshots: drop files in `static/<slug>/` and list them in the game JSON:

```json
"screens": [{"src": "../static/temtem/menu.png", "alt": "Menu chính tiếng Việt",
             "caption": "Menu chính"}]
```

## 8. Checks before pushing

```bash
python3 build.py && python3 - <<'EOF'
import pathlib
for f in ["index.html", "temtem/index.html"]:
    assert "Việt Hóa" in pathlib.Path(f).read_text(encoding="utf8")
print("ok")
EOF
```

Then open the page locally (`file://$(pwd)/temtem/index.html`) — paths are
relative on purpose, so it renders without a server and works both at
`/viethoa/` and on a custom domain.
